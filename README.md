# 학사력

교무실에서 쓰는 학사일정 앱. 파일 하나(`index.html`)로 돌아가고, 빌드 도구도 서버도 없다.
데이터는 구글 스프레드시트 6개 시트를 gviz JSONP로 그대로 읽어 온다.

```
index.html                     ← 지금 쓰는 버전
archive/index-legacy-v2.html   ← 이전 운영 버전 (2025년형)
archive/index-draft-v3.html    ← 정리안 초안
```

## 화면

| 화면 | 하는 일 |
| --- | --- |
| 오늘 | 오늘 일정, 오늘 경건회·자습감독, 내 당번 D-day, 이번 주, 앞으로 3주 |
| 달력 | 월 격자. 주말을 접으면 토·일 일정이 금요일 칸으로 모인다. 연간 보기 |
| 월중 계획 | 인쇄용 표. 경건회·자습감독 칸, 한 줄 배열 |
| 학생일정 | 학생 일정만 모은 월 표 |
| 부서별 | 한 부서의 일정을 월별로. `.ics` 내보내기 |
| 누가기록 | 학년·영역별 창체 이수시간 집계 |
| 수정 요청 | Apps Script 웹앱으로 요청 전송 |

## 알아 둘 것

**내 이름** — 설정(⚙)에 이름을 넣으면 자습감독·경건회 표에서 내 차례를 찾아
`D-3` 같은 형태로 알려 주고, 표에서 내 이름에 도장(■)을 붙인다. 이름은 이 기기의
`localStorage`에만 있고 어디로도 전송되지 않는다.

**인쇄** — `인쇄` 버튼은 A4 세로 한 장 미리보기를 연다. 글자 크기는 자동으로 정해지고,
너무 작아지면 어떤 옵션을 끄면 커지는지 알려 준다. 내용을 자르는 일은 없다.
`Ctrl+P`로 바로 인쇄해도 같은 결과가 나온다.

**오프라인** — 마지막으로 받은 내용을 `localStorage`에 두어, 연결이 안 되면 저장본을
먼저 보여 준다. 화면이 비는 일이 없다.

**단축키** — `1`–`7` 화면 이동, `/` 검색, `←` `→` 이전·다음 달, `T` 오늘,
`P` 인쇄, `R` 새로고침, `?` 도움말.

## 색

부서 19개에 색상(hue)을 하나씩 주고, 계열끼리 색상군으로 묶었다.
기획·행정은 청람, 학생지원은 자주, 학년부는 황토, 인문교과는 초록, 자연·예체능은 청록.
색은 `--dh`(색상)·`--ds`(채도)를 요소에 주입하고 CSS가 칩·괘선·글자색을 만든다.
명도와 채도 보정치는 라이트/다크에서만 갈린다(`--tint-l`, `--label-l`, `--edge-l` …).

> 파생 색을 `:root`에서 조립하면 안 된다. 커스텀 속성은 **선언된 요소에서** 값이 정해지므로
> `:root`에는 `--dh`가 없어 색 전체가 죽는다. 반드시 쓰는 자리에서 `hsl()`을 만든다.

창체 4개 영역 색은 라이트/다크 각각 명도대역·채도 하한·색각이상 분리·대비 검사를 통과한 값이다.

## 되돌리기

이전 버전으로 되돌리려면 원하는 파일을 `index.html` 자리에 놓으면 된다.

```bash
git checkout main -- index.html          # 이전 운영 버전으로 통째 되돌리기
cp archive/index-legacy-v2.html index.html   # 파일만 바꿔치기
cp archive/index-draft-v3.html index.html    # 정리안 초안으로
```

`archive/`의 두 파일은 그 자체로 완결된 앱이라 브라우저에서 바로 열어 비교할 수 있다.
저장된 설정 키는 버전마다 다르므로(`hs-calendar-prefs-v1` ↔ `academic-calendar-*`)
되돌려도 서로 간섭하지 않는다.

## 손볼 때

`index.html` 한 파일 안에 순서대로 들어 있다.

```
<style>   1 토큰 · 2 공통 조각 · 3 골격 · 4 무대 · 5 오늘 · 6 달력 · 7 표
          8 부서별 · 9 누가기록 · 10 요청 · 11 다이얼로그 · 12 인쇄 · 13 반응형 · 14 인쇄
<script>  1 설정 · 2 유틸 · 3 상태 · 4 데이터 · 5 조회 · 6 뼈대 · 7 화면들
          8 그리기 · 9 하루 상세 · 10 ics · 11 인쇄 · 12 설정 · 13 요청 · 14 조작 · 15 시작
```

시트를 바꿨다면 `CONFIG.SHEETS`의 `gid`, 부서를 늘렸다면 `DEPARTMENTS`(이름·색상·채도)만
고치면 된다.
