## 화면

`달력` `월중 계획` `학생일정` `부서` `누가기록` `수정 요청` — 여섯 개.

## 동작

- **자료 출처** — 화면 맨 아래 접이식. 시트별 행 수·갱신 시각·실패 사유와, 읽지 못한 행을
  `연중행사계획 141행 · 날짜를 읽을 수 없습니다` 처럼 짚어 준다. 원자료 링크로 그 시트를 바로 연다.
  앱이 시트를 못 고치니, 무엇이 잘못됐는지는 알려 줘야 한다.
- **연간 보기** — 열두 달을 미니 달력으로 한 화면에. 날짜마다 건수, 달마다 합계. 눌러서 상세로.
- **주말 접기** — 달력에서 주말을 끄면 토·일 일정이 금요일 칸 아래로 모인다. 일정이 사라지지 않게.
- **인쇄** — A4 세로 한 장 미리보기. 글자 크기를 자동으로 정하고 남는 세로는 행이 나눠 갖는다.
  너무 작아지면 어떤 항목을 끄면 커지는지 알려 준다. `Ctrl+P`도 같은 결과.
- **중복 제거** — 같은 행사가 연중행사계획과 학생일정에 다 적혀 있으면 하루 상세에서 한 번만 나온다.
- **사본 보관** — 마지막으로 받은 자료를 `localStorage`에 둔다. 연결이 없으면 이 사본을 보여 줘
  화면이 비지 않는다. 5분마다 갱신. 사본으로 보여 주는 중이면 출처 패널이
  `140행 저장본 · 연결하지 못했습니다` 처럼 밝히고, 같은 자리에서 `사본 비우기`를 할 수 있다.
- **응답 검증** — gviz 는 권한 오류도 HTTP 200 으로 준다. `status`와 표 구조를 직접 확인하고,
  시트가 돌려준 사유(`이 문서에 접근할 권한이 없습니다`)를 그대로 보여 준다.
- **빈 날 숨김** — 월중 계획·학생일정에서 일정 없는 날을 접는다. 인쇄에는 영향이 없다.
- **단축키** — `1`–`6` 화면, `/` 검색, `←` `→` 달, `T` 오늘, `P` 인쇄, `R` 새로고침.

## 색

창체 영역(자율자치·봉사·동아리·진로)도 같은 방식으로 색을 나눈다. `CAT_TONE` 참조.

부서 19개에 색상(hue)을 하나씩 주고 계열끼리 묶었다.
기획·행정 청람 / 학생지원 자주 / 학년부 황토 / 인문교과 초록 / 자연·예체능 청록.
요소에 `--dh`(색상) `--ds`(채도)를 주면 CSS가 칩·괘선·글자색을 만든다.

> 파생 색을 `:root`에서 조립하면 안 된다. 커스텀 속성은 선언된 요소에서 값이 정해지므로
> `:root`에는 `--dh`가 없어 색이 전부 죽는다. 반드시 쓰는 자리에서 `hsl()`을 만든다.

서체는 Pretendard 하나. 웹폰트가 막히면 시스템 고딕으로 떨어진다.

## 모바일: 꽃달력 (`mobile/`)

같은 시트를 휴대폰에서 보는 별판. 위 앱과 코드를 나누지 않는다.
**위 앱의 제목 `학사일정`을 누르면 꽃달력이 그 화면 위로 열리고, 꽃달력의 제목 `꽃달력`을 누르면 돌아온다.**
열린 상태는 주소 끝 `#kkot` 이라 휴대폰의 뒤로 가기로도 돌아오고, `…/#kkot` 주소로 바로 열 수도 있다.
꽃달력은 한 번만 불러와 두므로 두 번째부터는 바로 바뀐다. `mobile/` 을 따로 열면 제목이 학사일정으로 가는 링크다.

하루는 꽃 한 송이다. 만화처럼 굵은 먹선, 납작한 색, 꽃잎 밑동의 그늘, 흰 반사광으로 그린다.

| 그림 | 시트에서 |
| --- | --- |
| 꽃잎 수 | 그날 `[부서]`가 붙은 일정 수. 꽃잎은 목록 순서대로 12시부터 시계 방향 |
| 꽃잎 색 | 부서. 자주 나오는 부서부터 만화 색 12가지를 차례로 나눠 준다(`DEPT_COLORS`) |
| 꽃잎 글자 | 부서 줄임말: `1학년부` → `1`, `교무부` → `교무`, `기획위원` → `기획`. 누르면 말풍선에 그 일정 |
| 꽃 크기 · 단계 | 올해 수업일 가운데 그날이 얼마나 활짝 피었는지: 봉오리 · 피는 중 · 활짝 · 만개(반짝이) |
| 새싹 | 할 일이 없는 날(쉼). 부서 없는 줄(`삼일절 대체공휴일`)은 메모로 붙는다 |
| 목록 오른쪽 막대 | `(①②③,6-7)` 의 교시 |

**일정 이름의 뜻은 읽지 않는다.** "시험이면 ~" 같은 낱말 목록은 없고, 꽃은 시트의 수와 모양에서만 나온다.

1. 일정 하나의 무게 = 드문 정도 × 차지하는 교시 × 연달아 나오는 날 수
   - 드문 정도: `log2(1 + 할 일 있는 날 수 / 그 일정이 나오는 날 수)`. 매주 있는 부장회의는 가볍고 한 번뿐인 일정은 무겁다.
     "같은 일정"은 괄호·숫자·기호·띄어쓰기를 뺀 글자로 가른다(`1학기 중간고사 1일차` = `2학기 중간고사 2일차`).
   - 교시: 교시 하나마다 +15%. 연달아: 같은 일정이 앞뒤 수업일에 이어지면 하루마다 +25% (5일까지).
2. 하루 점수 = 그날 일정 무게의 합. ①②③ 처럼 학년이 여럿 적힌 일정은 학년 하나마다 +25%.
   `(~10/2)` 처럼 기간이 적힌 일정은 둘째 날부터 무게의 절반을 남긴다(이어지는 일정).
3. 핀 정도 = 올해 수업일 가운데 그날보다 점수가 낮거나 같은 날의 비율(1–99). 고른 부서마다 따로 센다.
4. 단계 = 핀 정도의 구간 (`STAGES`, 배지·한 해 보기 색은 `STAGE_COLOR`). 하위 30% 봉오리, 65%까지 피는 중, 90%까지 활짝, 가장 만개한 10% 만개.

- 화면: 오늘의 꽃(꽃잎을 누르면 말풍선으로 그 일정이 뜨고 목록의 그 줄도 켜진다) · 오늘의 꽃잎 · 앞으로 7일 · 곧 만개(날짜가 제목) · 정원(한 달/한 해).
  날짜를 누르면 그날 꽃이 아래서 올라온다. 교사용은 기도·야자 감독·공지를 함께 보여 준다.
- 머리의 `전체 부서 ▾` 에서 부서를 고르면 그 부서 일정만 꽃잎이 되고, 꽃이 핀 정도도 그 부서의 한 해 안에서 다시 센다.
- 시트 이름(`sheet=`)으로 읽으므로 gid 가 바뀌어도 된다. 탭 이름을 바꾸면 `SRC` 를 고친다.
- `?for=student` 로 열면 `(학생용)연중행사계획` 만 쓴다.
- 무게는 `weigh()`, 하루 계산은 `day()`, 꽃 그림은 `flowerSVG()`, 비율은 `*_SHARE` 상수.
- 서체: 제목·날짜는 주아(Jua), 본문은 나눔고딕.

## 되돌리기

```bash
git revert --no-edit <배포 커밋>          # 커밋 하나로 복귀
cp archive/index-v4-haksaryeok.html index.html   # 좌측 레일 · 오늘 화면이 있던 판
cp archive/index-v3-draft.html index.html        # 정리안 초안
cp archive/index-v2-legacy.html index.html       # 최초 운영본
```

`archive/`의 세 파일은 그 자체로 도는 앱이라 브라우저로 바로 열어 비교할 수 있다.
저장 키가 판마다 달라(`hs-prefs-v2` / `hs-calendar-prefs-v1` / `academic-calendar-*`)
오가도 설정이 섞이지 않는다.

## 손볼 때

`index.html` 한 파일. `<style>`은 토큰 → 조각 → 머리 → 화면별 → 인쇄 → 반응형 순,
`<script>`는 설정 → 유틸 → 상태 → 데이터 → 검색 → 그리기 → 하루 상세 → 인쇄 → 설정 → 요청 → 조작 순.

시트를 바꾸면 `CONFIG.SHEETS`, 부서를 늘리면 `DEPTS`(이름·색상·채도)만 고치면 된다.
